## Задание

Дан массив действительных чисел a0, ..., an-1.
Найти сумму всех элементов массива, в целой части которых
присутствует заданная цифра.

На вход функции передаётся массив действительных чисел.
Длина массива может быть любой.

Результат работы функции: массив подходящих элементов
и сумма целых частей этих элементов.

## Принятые правила

Функция возвращает подходящие исходные элементы и сумму
их целых частей согласно описанию выходных данных задания.

Целая часть получается отбрасыванием дробной части.
Например, для -21.4 целая часть равна -21.
При поиске цифры знак числа не учитывается.

Цифра задаётся отдельным параметром от 0 до 9.
Порядок элементов в результате совпадает с исходным.
Пустой массив допускается: результат пустой, сумма равна 0.

Элементы массива имеют тип double.
Целые части и их сумма хранятся в BigInteger.
NaN и бесконечности не допускаются.

Реализована функция отбора элементов и подсчёта суммы.

## Тестирование

Добавлены 12 тестов группы Flow и 18 тестов группы Condition.
Исходные данные и ожидаемые результаты формируются
скриптом tools/generate_tests.py на Python.

Тесты условий проверяют границы заданной цифры,
сравнение цифр, продолжение цикла и допустимость элементов массива.
